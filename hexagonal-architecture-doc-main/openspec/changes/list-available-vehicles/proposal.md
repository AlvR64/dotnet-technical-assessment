# Proposal

## Why
Los consumidores necesitan conocer qué vehículos están disponibles actualmente para alquiler.

## What Changes
- Añadir consulta REST de vehículos elegibles sin alquiler activo.
- Cubrir los límites temporales y la consulta de solo lectura.

## Capabilities
### New Capabilities
- `vehicle-availability`: consulta actual de vehículos disponibles.
### Modified Capabilities
Ninguna.

## Impact
Api, ApplicationCore, Infrastructure, pruebas y README.PRUEBA-TECNICA-ALVARO.md. Depende del modelo del plan 1 y se implementa después del alta. Sin modificar documentos originales.
